# BioNuclei-DomainRobust

## Domain-Robust Nuclear Instance Segmentation for Fluorescence Bioimaging

This repository develops and evaluates deep-learning methods for **nuclear instance segmentation under cross-domain fluorescence microscopy shift**.

### Research objective

The first study asks whether a nuclear segmentation model trained on a controlled fluorescence benchmark can generalize to heterogeneous human bioimaging data with changes in tissue preparation, magnification, signal-to-noise ratio, and biological context.

The initial experimental sequence is:

```text
BBBC039
  ↓
Boundary-aware nuclear instance segmentation
  ↓
Held-out BBBC039 evaluation
  ↓
Zero-shot transfer to S-BIAD634
  ↓
Quantify domain shift
  ↓
Domain-robust training / adaptation
  ↓
Few-shot adaptation
  ↓
Independent external validation
```

### Dataset policy

The repository does **not** redistribute third-party datasets. It stores dataset manifests, acquisition instructions, preprocessing code, configuration, and validation metadata. Raw images and annotations must be obtained from their authoritative repositories and used according to their licenses/terms.

Initial datasets:

- **BBBC039** — Broad Bioimage Benchmark Collection nuclear fluorescence benchmark.
- **S-BIAD634** — BioImage Archive human fluorescence nuclear dataset used for cross-domain evaluation.

Later-stage validation may include **ORION-CRC / HTAN** after the core domain-generalization experiments are established.

### Reproducibility principles

- Biological-group-aware train/validation/test splitting.
- No random patch leakage across the same source image, sample, patient, or preparation group.
- No fabricated experimental results.
- Every reported metric must be generated by a versioned experiment.
- Dataset versions/accessions and preprocessing choices are recorded.
- Baselines are retained and compared before claiming improvement.
- Novelty claims are treated as hypotheses until supported by literature review.

### Project status

**Phase 0 — repository and reproducibility scaffold.**

The next phase is real-data validation of the existing boundary-aware segmentation baseline, followed by rigorous cross-domain experiments.

### Research structure

- `src/` — reusable Python package
- `configs/` — experiment configurations
- `scripts/` — command-line entry points
- `tests/` — unit and integration tests
- `docs/` — research notes, protocols, dataset documentation
- `data/` — local-only dataset mount points; raw data are gitignored
- `outputs/` — local experiment outputs; results should be committed only when intentionally curated

### Related prior work

The project uses existing nuclear-segmentation methods as baselines and does not present the baseline architecture itself as novel. The scientific contribution will be determined only after empirical cross-domain results and a focused literature audit.
