E5 run 33829770022 completed successfully, but its retained artifact exposed an integrity failure: only the two ablation directories were present and the required full_frozen_e4 result was absent. The run is therefore not accepted as E5 scientific evidence.

Artifact audit

Artifact e5-ablations-33829770022 is retained with digest sha256:8fa4694f443208ffdc5aabe2c2e91086cfb3fc927425acb9060532797c2383f1. Independent inspection found complete 79-image metrics for no_intensity_randomization and no_contrast, but no full_frozen_e4 directory.

Concrete fix

Baseline evidence

The corrected BBBC039 Boundary U-Net checkpoint from run 33768426630 is now pulled by its retained artifact and evaluated with the same target evaluator. Its source artifact, checkpoint, configuration, split and target-manifest provenance are retained; no published metric is copied.

Release gate

E5 remains open until a new run passes the strengthened completeness and baseline-provenance gates and the resulting per-image comparisons are independently cross-checked.
