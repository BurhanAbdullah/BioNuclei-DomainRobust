The aggregate workflow verified full_frozen_e4, no_intensity_randomization, and no_contrast, each with 79/79 target evaluations, required summary/per-image metrics, target-manifest provenance, checkpoint/configuration/split hashes, and explicit evidence that target data were not used for training.

Retained run · 2026-09-05

Run 33943463177 completed all three 20-epoch source-only variants, independently validated their retained artifacts, and completed the aggregate gate. The retained gate artifact is e5-gate-33943463177 with GitHub digest sha256:6274b9ab243536ca5d806f327c223f44b89fc4fdd65a47b947e93fe116eb0e5b.

The artifact audit also independently confirms the matched 79-image conventional comparator and its provenance. Observed metrics are retained in the machine-readable artifacts; downstream statistical/failure analysis remains a separate release gate.

Comparator evidence

The corrected conventional Boundary U-Net comparator was re-evaluated on the identical 79-image S-BIAD634 target set. Its source run, artifact digest, checkpoint hash, source split, target manifest, decoder, evaluator and no-target-training provenance are retained. Eligibility is an auditable evidence classification, not a copied published number.

Next release decision

E5 is no longer the blocker. The next required gate is E6, which remains blocked until an authoritative leakage-safe target adaptation pool and disjoint manifest are retained and independently validated. No biological-group inference is made from target filenames.
