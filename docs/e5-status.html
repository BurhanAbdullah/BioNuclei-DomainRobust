Controlled ablations and strong-baseline gate

E5 remains open. The previously retained run 33829770022 passed its then-current workflow checks and is retained, but it predates the strengthened release-integrity gate and is not used to infer completion of the current E5 gate.

Current integrity gate

The current workflow requires full_frozen_e4, no_intensity_randomization, and no_contrast, each with 79/79 target evaluations, required summary/per-image metrics, target-manifest provenance, and explicit evidence that target data were not used for training.

Runner hardening

The E5 runner now fails before training when either the source split manifest or target inventory manifest is missing, empty, or invalid JSON. This prevents an accidental incomplete inventory from producing apparently valid provenance.

Comparator evidence

The workflow independently evaluates the retained corrected conventional Boundary U-Net comparator on the identical 79-image target set and retains source artifact, checkpoint, configuration, split, target-manifest and evaluator provenance. No published metric is copied into the comparator record.

Next release decision

No E5 result is promoted until a fresh run from the strengthened implementation completes and its retained artifact is independently inspected and cross-checked. E6 remains separately blocked until a leakage-safe adaptation pool is established.
