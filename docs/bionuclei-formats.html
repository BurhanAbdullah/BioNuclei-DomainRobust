Input without guesswork

Bring the microscopy file you actually have.

BioNuclei currently accepts TIFF and Nikon ND2 for the public analysis workflow. The service does not silently collapse a multidimensional acquisition into an arbitrary plane.

Supported

TIFF / TIFF

2-D TIFF input can enter the current Boundary U-Net segmentation pipeline directly. The server records image shape, dtype and intensity statistics before inference.

Supported

Nikon ND2

ND2 files are read with the maintained nd2 package. When an acquisition has additional dimensions, BioNuclei requires an explicit channel, time, Z and field/position selection.

ND2 selection is explicit

ChannelC index
TimeT index
Z / FieldZ + position
Why: a Nikon acquisition may contain multiple channels, Z planes, time points and positions. BioNuclei records the source axes, sizes, selected indices, reader version and SHA-256 so the 2-D plane used for segmentation is reproducible.

More formats can be added safely.

BioNuclei should grow toward broad life-science format coverage, but each new reader needs a tested conversion path and provenance contract before it is exposed in the public analyzer.
