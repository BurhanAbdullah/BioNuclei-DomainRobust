Join BioNuclei with your GitHub identity.

Use your GitHub account to join the public research community. Your GitHub username and public profile are recorded in the project community registry, then displayed automatically on the People page.

Become part of the project

Join with GitHub.

Click the button, sign in to GitHub if needed, and submit the prefilled community-join request. GitHub identifies the request author automatically. A repository workflow then records the public profile and closes the request.

Continue with GitHub

Only your public GitHub username, profile URL and the public join-request reference are recorded. No GitHub password or private repository data is requested.

What good participation looks like

Science first. Code second. Claims last.

Useful contributions make the work easier to reproduce, easier to inspect and harder to misinterpret. That can mean better tests, clearer provenance, stronger baselines, improved documentation or a careful scientific objection.
