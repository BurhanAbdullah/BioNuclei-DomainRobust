BioNuclei • Interactive use

Use BioNuclei.

Inspect a fluorescence image, run nuclear instance segmentation, evaluate against ground truth, compute instance metrics, and inspect the resulting provenance. Scientific computation remains in the BioNuclei Python package.

What this page is.

This is the BioNuclei user interface. BioMCP is a separate optional interoperability layer. BioFM, BioWF and BioSkills are separate product/research directions and are not required to use BioNuclei.

Connect to a BioNuclei Web API

Not connected

The GitHub Pages site is static. Live PyTorch inference requires a separately deployed HTTPS backend. The repository includes webapp/app.py and webapp/render.yaml as deployment recipes.

Available BioNuclei operations

1 · Inspect imageDimensions, dtype and intensity statistics.
2 · PredictRun the Boundary U-Net and return a structured prediction bundle.
3 · EvaluateRun prediction plus Dice, IoU and Boundary-F1 against ground truth.
4 · Compute instance metricsCompute Dice, IoU, AJI and Boundary-F1 directly from masks.
5 · Read provenanceInspect machine-readable execution metadata.
6 · Read result summaryInspect a structured results.json bundle.

Scientific boundary

The browser interface does not invent metrics, select benchmark test sets, change experiment protocols, upload arbitrary checkpoints, or execute arbitrary shell commands. Registered E6/E7 experiments and release validation remain controlled scientific workflows.
