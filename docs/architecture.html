ArchitectureResearch direction

A common structure for scientific AI.

The proposed ecosystem separates model research, interoperability, workflow composition and reusable scientific knowledge. Each layer has a defined purpose and can be developed independently.

Ecosystem structure

Four complementary layers.

The architecture is a design framework for future research and software development. It does not imply that every layer is implemented.

01

BioFM

Domain aware vision and multimodal foundation-model research for biological imagery.

02

BioMCP

Proposed interoperability layer for typed discovery and invocation of bioimaging capabilities.

03

BioWF

Workflow layer for versioned, reproducible and auditable scientific studies.

04

BioSkills

Knowledge layer for reusable protocols, validation rules and failure analysis.

Capability structure

A future bridge can expose clear scientific operations.

These categories describe the intended tool surface. They are architectural targets rather than claims of completed integrations.

01

Image ingestion

Load and inspect microscopy data with explicit metadata and provenance.

02

Dataset quality

Check completeness, pairing, labels and declared split rules.

03

Preprocessing

Run explicit, versioned transformations using established tools.

04

Segmentation

Invoke segmentation models and return structured outputs.

05

Quantification

Compute scientific measurements inside deterministic analysis software.

06

Evidence records

Preserve metrics, parameters, artifacts and software provenance.

Interface principle

Separate coordination from computation.

An AI agent may help interpret a research request and coordinate available operations. The scientific tools remain responsible for image analysis, measurement and other domain specific computation.

Interfaces should expose inputs, outputs, constraints and provenance clearly enough for researchers to inspect what happened.
