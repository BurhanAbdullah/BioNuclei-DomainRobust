Four steps

From image to evidence

01 · Inspect

Confirm shape, dtype and intensity statistics before running the model.

02 · Predict

Produce integer-labelled nuclear instances plus a visual overlay.

03 · Evaluate

When ground truth exists, calculate supported metrics against it.

04 · Audit

Keep measurements, results and provenance with the output bundle.

Try the real package

Run BioNuclei locally in a clean environment.

python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -e .

bionuclei --help

bionuclei predict \
  --input my_fluorescence_image.tif \
  --checkpoint model.pt \
  --output results/

Evidence boundary
Arbitrary user images produce software outputs, not benchmark claims. Benchmark metrics require defined ground truth, a frozen protocol, and traceable machine-readable artifacts.
