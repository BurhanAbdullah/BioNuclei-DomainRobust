Local workflow

Recommended reproducible path

01

Create an environment

python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -e .
02

Check the CLI

bionuclei --help
bionuclei --version
03

Predict

bionuclei predict \
  --input my_fluorescence_image.tif \
  --checkpoint model.pt \
  --output results/
04

Evaluate

bionuclei evaluate \
  --input my_fluorescence_image.tif \
  --ground-truth ground_truth.png \
  --checkpoint model.pt \
  --output evaluation/
Output contract

Every prediction should leave an inspectable bundle.

results/
├── segmentation_mask.tif   # integer-labelled predicted instances
├── overlay.tif             # visual inspection image
├── measurements.csv        # area / centroid / bounding-box rows
├── results.json             # structured run summary
└── provenance.json          # execution and input metadata
Interpretation rule: outputs on arbitrary user images are software results. They are not automatically benchmark evidence. Benchmark claims require the defined dataset, ground truth, frozen protocol and traceable artifact chain.

Common problems

Fast troubleshooting

Wrong image shape

The current user-facing inference path expects a 2-D fluorescence TIFF.

Missing checkpoint

Prediction requires a compatible .pt checkpoint. The official permanent model release remains separate from temporary Actions artifacts.

Metrics unavailable

Accuracy metrics require a matching ground-truth mask. Without ground truth, inspect the prediction and measurements instead.

Web endpoint unavailable

Check the API base URL, HTTPS configuration, CORS policy and server-side BIONUCLEI_CHECKPOINT.

Scientific boundary
