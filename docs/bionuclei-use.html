Four-step workflow

A simple path for researchers and image-analysis users.

The interface is intentionally task-oriented. You do not need to understand the benchmark pipeline to use the local product.

01 · INSPECT

Check the image

Confirm dimensions, dtype and intensity characteristics before inference.

02 · PREDICT

Segment nuclei

Run the current BioNuclei model and generate instance-labelled segmentation output.

03 · EVALUATE

Measure quality

Provide a ground-truth mask to compute supported accuracy metrics.

04 · AUDIT

Inspect evidence

Review structured results and provenance before making scientific interpretations.

Real inference

Run BioNuclei locally.

The local CLI is the primary reproducible path. A compatible checkpoint is required for prediction or evaluation.

python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -e .

bionuclei --help

bionuclei predict \
  --input my_fluorescence_image.tif \
  --checkpoint model.pt \
  --output results/

bionuclei evaluate \
  --input my_fluorescence_image.tif \
  --ground-truth ground_truth.png \
  --checkpoint model.pt \
  --output evaluation/
Checkpoint status: do not use an expiring Actions artifact as a permanent public model download. The repository is keeping Release 1.0 fail-closed until the validated checkpoint/package is permanently published.

Output bundle

Results users can keep and inspect.

results/
├── segmentation_mask.tif   # integer-labelled nuclear instances
├── overlay.tif             # visual inspection overlay
├── measurements.csv        # per-instance measurements
├── results.json             # structured prediction summary
└── provenance.json          # execution + input metadata
For arbitrary user imagesBioNuclei produces software outputs and measurements. Do not infer benchmark accuracy without ground truth and the defined evaluation protocol.
For benchmark experimentsUse the registered research workflows. Their artifacts, manifests, hashes and statistical analysis are the authoritative evidence chain.
