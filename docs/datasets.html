Data discipline

Missing images should never disappear silently.

The evaluation protocol uses explicit inventories, deterministic pairing and hard gates. A result is meaningful only when the declared dataset, split and evaluation population can be reconstructed.

Longer term validation can extend to additional external datasets once the corresponding experiments are defined and executed.

Repository policy

Third party data stay with their authoritative providers.

The repository stores acquisition instructions, manifests, integrity checks and processing workflows. Raw third party datasets are not redistributed.

Read the dataset registry
Reproducibility principle

Every result should have a traceable data lineage.

A published result should connect to a dataset version, split definition, model configuration, execution record and evaluation artifact.
