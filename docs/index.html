BioNuclei is an automated analysis pipeline designed specifically for nuclear instance segmentation and quantification in fluorescence microscopy. AI predicts semantic regions; deterministic scientific software extracts individual nuclei, measurements and provenance.

Inside a BioNuclei run

Seven steps from file to evidence.

Each stage below is real code in the repository. Select one to see what it does, why it matters and what you get from it.

Built for real experiments

Bring the whole experiment, not one image.

The Lab checks every file before anything leaves your computer, then runs only what you choose.

1234

Experiment tray

Drop 5 to 20 images. Each is numbered, labelled by condition and replicate from its file name, and checked for format, size, bit depth, stacks and duplicates.

DAPI488594

Knows its channels

Reads channel names and wavelengths from ND2 and OME metadata, identifies common dyes, and analyzes the nuclear stain. It warns you if you pick another channel.

ReadyBrightfield

Says no, with a reason

Brightfield, histology, blank or tiny images are rejected with an explanation instead of producing numbers that look real but are not.

Reports you can audit

Masks, overlays, per-nucleus tables, specialist evidence with SHA-256 digests and provenance in one bundle. Your original image is never included.

For your research

Open, reproducible and citable.

  • Open source. MIT-licensed code, released checkpoint and every evaluation script on GitHub.
  • Reproducible. Each result records the checkpoint SHA-256, decoder, input hash and software version.
  • Private by design. Uploads are deleted after processing and never used to train the model.
  • Honest scope. 2-D fluorescence nuclei. Not for clinical diagnosis or whole-cell segmentation.

Scientific boundary

AI predicts. Deterministic scientific software measures.

BioNuclei is not a clinical diagnostic tool, not an online continuous-learning system, and not a general-purpose whole-cell imaging suite. Every result should remain inspectable and traceable to its computational provenance.
