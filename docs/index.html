A research initiative

Making bioimaging tools work together.

BioMCP explores a common agent accessible layer between researchers, AI systems and scientific software. The aim is to make complex image analysis easier to discover, execute, inspect and reproduce without replacing the tools that perform the science.

The idea

AI should coordinate scientific work, not obscure it.

BioMCP separates planning from measurement. An AI system can understand a research question, select tools and coordinate a workflow. The actual scientific operations remain explicit, typed and inspectable inside established bioimaging software.
