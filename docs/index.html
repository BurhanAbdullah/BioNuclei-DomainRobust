01 · Vision

From image analysis to an
auditable scientific agent.

The long-term goal is not “chat with an image.” It is a structured scientific interface: researchers express a question in natural language; an agent selects explicit tools; deterministic models and measurement routines execute the work; provenance and artifacts make the conclusion inspectable.

The principle

AI plans. Scientific software measures.

LLMs are positioned as an orchestration and reasoning layer—not as a substitute for segmentation, metric computation or experimental controls.

The promise

Open · Reproducible · Verifiable

Every scientific operation should have typed inputs, structured outputs, controlled execution and a traceable evidence chain.

The BioMCP ecosystem

A four-pillar architecture for agentic bioimaging, inspired by the general domain-agent pattern used in other scientific engineering ecosystems, but independently adapted to microscopy and biological data.

05 · Roadmap

Build the ecosystem on evidence.

Stage 1 · Current

Validate robustness

Freeze the baseline, compare against E4, quantify uncertainty and stratify failure modes.

Stage 2

Implement BioMCP

Build dataset, image, model, metric, experiment and provenance tool servers with explicit contracts.

Stage 3

BioWF + BioSkills

Turn validated experiments into reproducible workflows and reusable domain expertise.

Stage 4

Benchmark agents

Measure scientific correctness, tool reliability, reproducibility and agent failure modes across domains.

BioMCP, BioFM, BioWF and BioSkills are a proposed research architecture at this stage. They are not presented here as a completed validated platform. BioNuclei E4 is the demonstrated scientific substrate.
