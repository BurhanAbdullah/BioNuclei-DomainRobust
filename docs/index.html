An open research initiative

Reliable AI for biological imaging.

BioNuclei investigates how bioimaging AI can remain useful when image domains change, experiments are reproduced and scientific evidence is inspected.

The initiative studies robust scientific computation, reproducibility, provenance and trustworthy interfaces for biological imaging research.

Vision

Start with the scientific problem we want to solve.

We want bioimaging AI that is reliable beyond the conditions in which it was developed. That means studying domain shift, reproducibility, scientific provenance and failure modes while keeping the evidence inspectable.

The broader vision is to build trustworthy AI systems that can work with biological imaging tools and scientific workflows without hiding how scientific results are produced.
