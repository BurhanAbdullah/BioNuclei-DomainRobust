Introduction

Bioimaging is increasingly computational and increasingly fragmented.

Modern microscopy generates data that researchers analyze with a wide, specialized software ecosystem: tools for visualization, segmentation, tracking, quantification and data management. Each is powerful. Few speak to one another, and stitching them into a reproducible study is manual, slow and easy to get wrong. BioMCP explores how AI agents can connect these existing, trusted open source tools into workflows that are transparent, reproducible and scientifically accountable, rather than replacing them with a black box.

Why BioMCP

The problem is not a lack of tools. It is connecting them.

Researchers already have excellent open source software for nearly every step of bioimage analysis. What is missing is a common, agent accessible layer that can discover the right tool, run it correctly, and keep a trustworthy record of what happened.

Our vision

A researcher asks a question. Scientific software answers it.

The role of the agent is to plan and orchestrate, not to replace measurement. BioMCP is built around one non negotiable principle.

Built for the tools researchers already use
