BioNuclei-DomainRobust

Domain-robust nuclear instance segmentation for heterogeneous fluorescence bioimaging.

View GitHub repositoryAbout the project

Research question

Can a nuclear segmentation model trained on a controlled fluorescence benchmark generalize reliably to heterogeneous human fluorescence bioimaging without annotation leakage or arbitrary architecture changes?

Study pipeline

BBBC039 → boundary-aware segmentation → held-out evaluation → S-BIAD634 zero-shot transfer → domain-shift analysis → evidence-driven robustness → ablations → few-shot adaptation → external validation

Datasets

BBBC039

Controlled fluorescence nuclear benchmark used for source-domain training and held-out evaluation.

S-BIAD634 / S-BSST265

Heterogeneous human fluorescence nuclear-imaging benchmark used for cross-domain evaluation.

ORION-CRC / HTAN

Reserved for later multimodal cancer-tissue validation.
