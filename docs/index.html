Making bioimaging tools work together.

BioMCP explores a common agent accessible layer between researchers, AI systems and the open bioimaging software ecosystem. The goal is simple: make complex scientific workflows easier to discover, execute, inspect and reproduce.

Explore BioMCPExplore the research
The challenge

The tools already exist.

The missing piece is a trustworthy way for them to work together.

Bioimage analysis already has powerful software for visualization, segmentation, tracking, quantification and data management. Each tool solves a real scientific problem. Researchers still have to connect them manually, carry context between interfaces and document what happened.

BioMCP investigates whether an agent accessible interoperability layer can connect these tools while keeping the scientific computation inside established software.

The principle

AI coordinates the work. Scientific software performs the measurement.

The LLM is the planner and communication layer. Segmentation, quantification and validation remain explicit scientific operations performed by the selected tools.

The open ecosystem

Built around tools researchers already know.

BioMCP is not intended to replace the bioimaging ecosystem. It is intended to make that ecosystem more accessible to agents while preserving the underlying scientific tools.

Research foundation

BioNuclei is the scientific substrate.

The current repository studies domain robust nuclear instance segmentation across fluorescence imaging domains. That work provides a concrete scientific environment in which robustness, reproducibility and evidence can be tested.
