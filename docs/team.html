BioNuclei is designed as an open research initiative. Project leadership is shown explicitly, while people who join through GitHub are recorded automatically and displayed below.

Open contribution

Join by forking. Make a contribution.

BioNuclei is open to researchers, developers, students and microscopy enthusiasts. You do not need to be listed on this page first—start with the repository, make a meaningful contribution and submit it for review.

01

Fork the repository

Create your own GitHub copy of BioNuclei so you can work independently.

02

Choose something to improve

Code, tests, documentation, examples, UI, scientific validation, bug reports or a new analysis capability.

03

Build & test

Make a focused change, run relevant checks and explain what you changed and how you tested it.

04

Open a pull request

Submit your contribution to the main repository. Maintainers review it before merging.
