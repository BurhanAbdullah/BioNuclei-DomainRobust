S-BSST265

A target-domain dataset included in the S-BIAD634 / S-BSST265 acquisition and evaluation pathway for broader cross-domain robustness analysis.

Scientific role

Target-domain evaluation

S-BSST265 contributes to evaluation beyond the controlled source domain and is part of the broader target-domain robustness study.

Repository source

BioStudies

The repository acquisition script obtains the S-BIAD634 / S-BSST265 package from the EMBL-EBI BioStudies service.

Open source archive
Validation policy

Target-domain integrity is checked before evaluation.

The acquisition workflow records source provenance, verifies archive integrity, inventories raw images and ground-truth files, and records the expected public license.

Pairing

Image and ground truth correspondence

The inventory separates raw image files from ground-truth files so correspondence can be checked explicitly.

Integrity

Archive verification

The acquisition script tests the downloaded ZIP archive before extraction.

Provenance

Manifest recorded

The workflow records the source URL, archive SHA-256 and file inventory in a local manifest.

License

Public source terms

The repository records CC0 as the expected public license for the acquired package.

Repository handling

Inspect the acquisition workflow.

Raw third-party data are not committed to the repository. The acquisition and profiling code preserves the provenance needed to reproduce the data preparation step.
