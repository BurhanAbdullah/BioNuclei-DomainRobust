Step 1 · Choose one access mode

Start an analysis session

Guest mode needs no account. Account mode keeps your session across reloads. Both run the same released pipeline and the same deletion rules.

Create your BioNuclei account

Supabase Auth handles the password. BioNuclei never receives or stores it.

Sign in

Only the authenticated session is used to authorize your analysis job.

Continue without an account

Guest mode holds an ephemeral job token in this browser tab only. No account is created.

Step 2 · Image

Upload microscopy image

The file stays in browser memory until you press Analyze. This page never writes image data to browser storage. The server deletes the original after processing.
