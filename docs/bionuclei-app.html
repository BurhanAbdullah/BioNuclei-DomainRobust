Account or guest

Create an account if you want password based sign in. Already registered? Sign in. Prefer not to register? Continue as a guest. These modes are mutually exclusive on this screen.

New account

Create your BioNuclei account

Supabase Auth handles the password securely. BioNuclei does not receive or store your password.

After successful sign up, the workspace opens when Supabase returns an authenticated session. If email confirmation is enabled, follow the confirmation message and then use Sign in.

Existing account

Sign in

Use the email and password you registered with. Only the authenticated session is used to authorize your analysis job.

Guest

Continue without an account

Guest mode creates only an ephemeral job token in this browser session. No account is created and the token is not stored by BioNuclei as a password or profile.

Data lifecycle

Designed for disposable analysis

Account mode: Supabase Auth manages the account credential. The analyzer stores only transient job state needed while the analysis is running or waiting for your download.

Guest mode: no account is created. A high entropy job token is held in memory by this page so the guest can retrieve only their own job.

Image: the original upload is deleted by the backend when processing finishes. Results are retained for a short period so the report can be downloaded, then can be deleted immediately.

Research training: user uploads are not silently added to a training corpus. The current Boundary U-Net weights are not updated during a user analysis.
