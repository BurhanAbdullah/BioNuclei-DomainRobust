Evidence constrained

Expert analysis layer

Specialist agents review measured evidence and the scientific report. They do not change model weights during a user analysis and do not invent unsupported biological conclusions.

Data lifecycle

Designed for disposable analysis

Account mode: Supabase Auth manages the credential. The analyzer uses the authenticated session to authorize the current job.

Guest mode: no account is created. A high entropy job token is held in browser memory for the current session.

Image: the original upload is deleted by the backend after processing. Results expire after a short retention window or can be deleted immediately.

Interactive review: measurements and ROI summaries are rendered in the browser from the returned analysis artifacts. They are not silently added to model training.

Research training: the released Boundary U-Net weights are not updated during user analysis.
