S-BIAD634

A heterogeneous human target-domain dataset used in the BioNuclei cross-domain transfer and failure-analysis pathway.

Scientific role

Target-domain evaluation

S-BIAD634 is used to study how a source-domain segmentation model behaves when the microscopy domain changes.

Authoritative provider

BioImage Archive

The repository records S-BIAD634 as an EMBL-EBI BioImage Archive accession.

Open dataset information
Validation policy

Target data remain separate from source training.

The target-domain protocol requires explicit accession and download records, preservation of metadata needed for biological-group splits, deterministic handling of dependent images or patches, and verification of annotation and image correspondence.

Zero shot

No target labels for transfer

The experiment matrix defines the target domain without training labels for zero-shot evaluation.

Pairing

Correspondence must be verified

Image and annotation correspondence is checked before target-domain training or evaluation uses the data.

Splits

Dependent data stay together

The repository policy avoids random splitting of dependent images or patches.

Provenance

Accession and acquisition recorded

The accession and download date are part of the dataset record.

Repository handling

Inspect the acquisition and validation policy.

The repository does not redistribute third-party raw data. Acquisition scripts and manifests record how the public dataset is obtained and checked.
