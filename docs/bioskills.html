BioSkills is the layer for reusable domain instructions — protocols, validation rules, failure-mode checklists and task-specific capabilities that an agent can draw on across studies.

What is it?

Domain expertise the agent doesn't have to relearn

Good bioimage analysis relies on accumulated know-how: how to detect leakage between source and target domains, how to interpret a low boundary-F1 score, when a metric is misleading for a given tissue type. BioSkills is the direction for capturing this as reusable, versioned instructions the agent can apply consistently.
