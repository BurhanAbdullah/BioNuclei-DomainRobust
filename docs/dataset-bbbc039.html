BBBC039

The supervised source-domain benchmark used for the current BioNuclei nuclear instance segmentation experiments and controlled source evaluation.

Scientific role

Source-domain benchmark

BBBC039 provides the declared source domain for supervised model development and source evaluation.

Authoritative provider

Open official dataset page
Dataset record

What the repository expects to verify.

The current registry describes BBBC039 version 1 as 200 fluorescence fields of view from the Hoechst DNA channel of U2OS cells, with 520 by 696 pixel, 16 bit TIFF images and manually annotated nuclei.

Archives

Images, masks and metadata

The acquisition policy uses the official images, masks and metadata archives and keeps raw data outside Git.

Splits

Official partitions

The repository policy preserves the official train, validation and test assignment rather than redefining the split.

Integrity

Local verification

Acquisition manifests record download dates and archive hashes. The BBBC039 verifier must pass before a run treats the dataset as acquired.

Mask handling

Instance identities preserved

Color coded PNG instance masks are decoded into integer labelled matrices without changing object identities.

Reproducibility

The dataset record is part of the evidence chain.

Exact acquisition details belong in the local manifest. Expected counts and dimensions are checks to be verified from the actual files, not assumptions.
