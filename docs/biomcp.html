Agentic interoperability
for bioimaging.

BioMCP is the layer that lets an AI agent discover, call and trust the open-source bioimaging tools researchers already use — through typed tool contracts, structured results and traceable provenance.

What is BioMCP?

An interoperability layer, not another analysis tool

BioMCP does not reimplement segmentation, tracking or quantification. It defines a common, typed interface so an AI agent can discover the right bioimaging tool for a task, call it with valid parameters, and receive a structured, checkable result — with every step recorded.

Not a chatbot for images

An LLM describing an image from pixels alone offers no verifiable measurement.

Not a replacement tool

Fiji, napari, CellProfiler, ilastik and others remain the tools doing the work.

Why MCP for bioimaging

Bioimaging needs typed tools, not free-form prompts

Model Context Protocol gives agents a standard way to discover and invoke external tools with defined inputs and outputs. Bioimaging is a strong fit: images, masks, metadata, models and metrics can all be expressed as typed objects with clear provenance, instead of ambiguous natural-language instructions handed to a black box.

Architecture

Researcher → agent → BioMCP → tools → evidence → memory

The LLM plans, interprets and communicates. It does not perform the segmentation or measurement itself — that happens in the open-source bioimaging tool the workflow calls. A learned decision policy (DQN/RL) is a proposed future layer for sequential tool-selection decisions, not a claim of current implementation.

Tool interface

Discovery, execution, structured results, provenance

Tool discovery

The agent inspects available tool contracts — inputs, outputs, constraints — before choosing one.

Tool execution

Calls run with validated parameters against the deterministic underlying software.

Structured results

Outputs return as typed, machine-readable objects, not free text.

Provenance

Every call is logged with configuration, versions and artifacts for later audit.

Agent orchestration

Planning, memory and learned decisions
