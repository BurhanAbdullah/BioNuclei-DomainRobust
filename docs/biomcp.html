BioMCPProposedInteroperability

Connect AI agents to bioimaging software without hiding the science.

BioMCP is a proposed Model Context Protocol based research direction for connecting AI agents with established open source imaging software through explicit interfaces, structured results and inspectable provenance.

What it is

An interoperability layer, not another analysis application.

The purpose is to make scientific capabilities discoverable and callable without moving scientific computation into the language model.

01

Discovery

Expose available operations, inputs, outputs and constraints so an agent can identify a suitable scientific tool.

02

Execution

Invoke selected operations with validated parameters and a declared software environment.

03

Structured results

Return machine readable outputs that can be checked, compared and passed to later workflow steps.

04

Provenance

Preserve versions, parameters, inputs, outputs and artifacts so a result can be reconstructed.

Agent role

The LLM is the planner, not the measuring instrument.

The boundary is intentional: language models coordinate and communicate; scientific software performs domain-specific computation.

Coordination

What the agent can do

Interpret a research question, identify suitable operations, coordinate a workflow and explain the resulting evidence.

Scientific computation

What the agent must not replace

The scientific software that performs segmentation, measurement, visualization and other domain-specific computation.

From question to evidence

Every transition should remain inspectable.

A proposed agentic workflow can be represented as explicit stages, with each handoff preserving the information needed to inspect what happened.

01

Researcher

Defines the scientific question and constraints.

02

LLM agent

Plans a sequence of scientific operations.

03

BioMCP

Provides typed interfaces for discovery and invocation.

04

Scientific tools

Perform image analysis and measurement.

05

Validation

Checks outputs and experimental requirements.

06

Evidence

Records results, parameters and provenance.

Status

BioMCP remains a proposed research direction.

The architecture describes an intended interoperability model. It should be presented as implemented only after its components exist, interfaces are tested and real scientific workflows have been evaluated.
