BioMCPInteroperabilityOpen research

Agentic interoperability for bioimaging.

A common layer for AI agents to discover scientific tools, invoke them with explicit contracts and preserve the context needed to understand what happened.

What it is

An interoperability layer, not another analysis application.

BioMCP does not attempt to replace segmentation, tracking, visualization or quantification software. The underlying scientific computation stays in the tools that researchers already use.

The research question is whether those capabilities can be exposed to agents through clear interfaces that make tool selection, execution and provenance inspectable.

Core capabilities

Four things the layer must make explicit.

01

Discovery

Expose available operations, inputs, outputs and constraints so an agent can choose a suitable scientific tool.

02

Execution

Invoke the selected operation with validated parameters and a known software environment.

03

Structured results

Return machine readable results that can be checked, compared and passed to later workflow steps.

04

Provenance

Preserve versions, parameters, inputs, outputs and artifacts so a result can be reconstructed.

Agent role

The LLM is the planner, not the measuring instrument.

The agent can interpret a research question, select candidate operations and explain the resulting evidence. The actual scientific measurement remains inside the selected bioimaging software.

Example

A scientific question becomes a documented workflow.

“Does this segmentation model generalize to a new microscopy domain?”
Agent planning

Choose the operations

Dataset inspection, preprocessing, segmentation, metric calculation and evidence capture.

Scientific execution

Run the actual tools

The segmentation model and evaluation code perform the measurement. The agent does not invent the result.
