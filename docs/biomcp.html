BioMCPImplemented tool layerInspectable

Use BioNuclei through tools that keep the science underneath.

BioMCP is the interoperability layer around the deterministic BioNuclei package. It exposes typed scientific operations through MCP and a deployable web API while keeping segmentation, measurement and evaluation inside the scientific Python implementation.

Open interactive consoleRead repository docs
Implemented surface

Core tools are callable without an LLM.

The same operations are available to humans, automation and MCP hosts. Registered research experiments remain separate and controlled.

01
inspect_image

Inspect 2-D fluorescence image shape, dtype and intensity statistics without model inference.

02
predict_image

Run the deterministic BioNuclei segmentation bundle and produce structured results plus provenance.

03
evaluate_image

Run segmentation against ground truth and report the package-level evaluation metrics.

04
compute_instance_metrics

Compute Dice, IoU, AJI and Boundary-F1 directly from integer instance masks.

05
read_provenance

Inspect machine-readable execution provenance as a first-class result.

06
load_result_summary

Read structured result summaries so downstream agents can reason over actual outputs.

Run it

Connect an MCP host or use the web console.

For local agent integration, install the optional MCP extra and launch the server over stdio. For a shared web deployment, run the FastAPI adapter over Streamable HTTP/HTTPS and point the public console at it.

MCP v2stdioStreamable HTTPFastAPIPython 3.10+
python -m pip install -e '.[mcp]'
bionuclei-mcp

# web service
python -m pip install -e '.[web]'
BIONUCLEI_CHECKPOINT=/absolute/path/model.pt \
uvicorn webapp.app:app --host 0.0.0.0 --port 8000

The public console cannot become a hosted scientific service until a server operator supplies a validated model checkpoint and deploys the web adapter. The repository does not claim that a live public endpoint exists until that deployment is actually verified.

Scientific layer

Performs segmentation, instance separation, metrics and evaluation. Registered E6/E7 research workflows remain controlled release evidence and are not exposed as arbitrary public jobs.
