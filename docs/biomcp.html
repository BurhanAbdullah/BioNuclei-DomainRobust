BioMCP connects AI agents to real scientific software.

BioMCP is a separate, open-source interoperability platform for biology, bioinformatics, bioimaging and scientific AI. It provides the MCP layer that lets compatible AI hosts discover and invoke scientific tools while the underlying software remains responsible for computation, measurement and validation.

What is BioMCP?

An interoperability layer, not a replacement for science.

Modern biological research already has powerful open-source software. BioMCP addresses the missing connection between those tools and AI agents: discovery, typed tool contracts, routing, configuration, validation and evidence-aware interoperability.

AI hosts and agents

Plan a task, discover available capabilities, select an appropriate tool and explain the resulting workflow. The agent should not invent a scientific measurement.

BioMCP

Provides registry metadata, MCP tool schemas, routing, server configuration, diagnostics and integration lifecycle management.

Scientific software

Performs the domain-specific operation: image analysis, molecular visualization, sequence analysis, simulation, workflow execution or another validated computation.

How it works

From a research question to an auditable operation.

01 · Researcher

Defines the scientific question or workflow.

02 · AI host / agent

Plans, discovers and selects a suitable MCP capability.

03 · BioMCP

Routes a typed tool call and applies integration/configuration controls.

04 · Scientific software

Performs the actual computation or measurement.

05 · Result + evidence

Returns structured output with provenance where supported.

Scientific boundary

AI orchestrates. Scientific software measures.

BioNuclei remains the scientific source of truth for its own models, measurements, evaluation, artifacts and provenance. BioMCP does not copy or reimplement the BioNuclei scientific engine.

What can users do?

Three practical ways to use BioMCP.

1. Use existing servers

Install BioMCP and use its current local server families for supported image analysis, ImageJ/Fiji interoperability and an OpenAI-compatible LLM endpoint.

Start: pip install biomcp

2. Connect an AI host

Generate MCP configuration for supported clients such as Claude Desktop, Codex or a generic MCP host. Preview changes with --dry-run before writing configuration.

3. Build an adapter

Develop an integration for an open scientific project such as PyMOL, CellProfiler or BLAST+. New adapters begin as planned and become installable only after tests and validation.

Installation

Start locally in minutes.

pip install biomcp
biomcp list
biomcp doctor

# Run a current server
biomcp run bioimage

# Generate generic MCP configuration
biomcp install --servers bioimage --clients generic

# Preview without writing configuration
biomcp install --servers bioimage --clients generic --dry-run

Image-analysis dependencies can be installed with pip install 'biomcp[bioimage]'. ImageJ/Fiji requires an explicitly configured local executable. The LLM bridge uses environment-provided endpoint and credential configuration.

How to contribute

Help add the open scientific software ecosystem.

BioMCP is designed to grow through small, reviewable adapters rather than speculative wrappers.

Choose one workflow

Start from a concrete scientific use case and identify the upstream project, executable or library and its supported interface.

Implement safely

Define typed MCP inputs/outputs, validate paths and parameters, bound resources and subprocesses, and expose useful provenance.

Prove it

Add unit/integration tests, real MCP interoperability tests where applicable, packaging checks, documentation and CI evidence.
