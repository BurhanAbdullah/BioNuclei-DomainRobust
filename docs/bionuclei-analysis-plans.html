Why this is different

AI chooses the workflow; it does not invent the measurement.

BioNuclei can use an agent to help select an appropriate analysis plan, but the actual segmentation, measurements and scientific metrics are executed by fixed, testable software. This keeps the user experience simple while keeping the scientific computation auditable.

For advanced workflows: the platform can expose more algorithms as they are installed and scientifically validated. It will not silently swap models or turn an unvalidated method into a benchmark claim.
