BioNuclei hides the low-level image-processing chain behind a small set of user-facing analysis goals. Each enabled analysis has a defined input, method and output. New algorithms are only exposed after repository validation.

Find & count nuclei

Identify individual nuclei with the current Boundary U-Net segmentation pipeline and deterministic instance separation.

Input: 2-D fluorescence image
Output: labelled mask, overlay, nucleus count
Table: per-nucleus measurements
Available

Measure morphology

Quantify the geometry of each detected nucleus so users can inspect population-level shape distributions.

Measures: area, perimeter
Shape: eccentricity, solidity, circularity
Axes: major/minor axis length

Measures: mean intensity
Extremes: min / max intensity
Output: per-nucleus intensity report
