# BioMCP changelog

## 0.1.0

Initial standalone interoperability surface.

- Added `biomcp install` for MCP client configuration.
- Added `biomcp list` for server-pack discovery.
- Added `biomcp doctor` for local readiness checks.
- Added `biomcp run bionuclei` for stdio server launch.
- Added committed example client configuration and registry metadata.
- Exposes the six canonical BioNuclei-backed MCP tools without duplicating scientific measurement logic.
- Supports the same server over stdio and Streamable HTTP.
